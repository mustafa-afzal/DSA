# DSA

My ongoing work through data structures and algorithms in Python.

## [neetcode-150/](neetcode-150/)

Solutions to the NeetCode 150. Files are grouped by pattern (two pointers, sliding
window, binary search, stack, linked list, etc.) rather than one file per problem, so
each file reads as a running log of a single topic. Every solution is commented with
the problem name above it.

The goal here is pattern recognition — being able to look at a new problem and know
which technique it wants — not memorizing individual answers.

## [scratchwork/](scratchwork/)

Where I actually learn the concepts. Instead of just using Python's built-ins, I
implement the underlying structures and techniques from scratch (e.g. a hash map with
its own bucket/collision handling) to understand how they work before applying them to
problems.

## Running

Plain Python, no dependencies:

```bash
python3 neetcode-150/two-pointers.py
```
